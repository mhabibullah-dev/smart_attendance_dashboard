Heading: Introduction

Text:
  This assignment implements a Smart Attendance Dashboard for students using
  the Flutter framework. The application is built entirely within a single
  file — main.dart — without any external packages or additional Dart files.

  The app consists of two screens:

  Screen 1 (Student Info Screen): Displays the student's name, registration
  number, session, department, and university using value widgets (Text, Icon,
  ElevatedButton). Tapping "Mark Attendance" navigates to Screen 2 and passes
  the student name and registration number as route arguments.

  Screen 2 (Attendance Screen): Shows a non-editable TextField with the
  registration number received from Screen 1. A ListView contains six
  hardcoded subjects. Each subject card has two number TextFields (total
  lectures and attended lectures), a "Calculate" ElevatedButton, and a Text
  widget that displays the calculated attendance percentage for that subject.
  A "Calculate Overall Attendance" button at the bottom computes and shows the
  average percentage across all subjects.

Heading: Objective

Text:
  To demonstrate the use of Flutter's layout widgets (Column, Row, ListView,
  Expanded) and value widgets (Text, TextField, Icon, ElevatedButton) together
  to build an interactive student attendance management interface.

Heading: Explanation

Copy the following text EXACTLY into this section of your PDF:

---

  1. Layout Widgets: Column organises all UI sections top-to-bottom on both
     screens. Row lays out the two TextFields (total / attended) side by side
     in each subject card, and ListView stacks all subject cards vertically
     inside a scrollable view. Expanded ensures widgets fill available space.

  2. Value Widgets: Text displays static and dynamic data (student info and
     attendance percentages). TextField captures numeric input from the user
     (total and attended lectures). ElevatedButton triggers both per-subject
     and overall calculations, and Icon provides visual cues for each category.

  3. Widget Rebuilding: setState() is called inside _calculateSubject() and
     _calculateOverall(). Every setState() call marks the widget as "dirty",
     causing Flutter to schedule a rebuild. During the rebuild the updated
     _subjectPercentage list and _overallAttendance value are read from state,
     so the Text widgets that render percentages automatically show the new
     values — no manual DOM manipulation required, Flutter handles it all.

---

Heading: Conclusion

Text:
  This Smart Attendance Dashboard demonstrates how Flutter's layout and value
  widgets work together to create an interactive, data-driven mobile application.
  By combining Column, Row, ListView, and Expanded for structure with Text,
  TextField, Icon, and ElevatedButton for interaction, the app achieves a clean
  and functional design. The setState() mechanism ensures the UI remains
  synchronized with the underlying data without any additional state management
  packages.
